# ATM System

A simple ATM system built with Python using object-oriented programming.

## Features

* Create PIN
* Deposit money
* Withdraw money
* Check balance
* PIN verification
* Simple command-line interface

## Tech Stack

* Python
* Object-Oriented Programming (OOP)

## Usage

Run the Python file and select an option from the ATM menu.

You can create a PIN, deposit money, withdraw money, and check your balance.
